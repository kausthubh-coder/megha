# Direction

Subject: megha, an open-source ACP agent that runs T3 Code (and Zed) threads on Codex Cloud and Claude Code on the web. For developers who already use T3 and pay for ChatGPT or Claude.
Job: say what it is in one line, show a T3 thread running in the cloud, and get the install prompt copied.
Kept: B, centered headline with one solid "Copy install prompt" button and a large thread mock under it; the product shows on the first screen at 1440 and 390. Also tried: A, two columns with the prompt text beside a smaller mock; on a phone the mock fell below the fold and the prompt box competed with the headline.
References: Stripe Payments (working UI right under the headline), Linear's changelog (one quiet family, product screens carry the color), the T3 Code app itself (the thread layout people will recognize).

## Materials
- Type: Instrument Sans (headings and body, 400/500/600), JetBrains Mono (commands, paths, logs, the prompt).
- Palette: monsoon slate. Light ground oklch(0.985 0.004 250), ink oklch(0.22 0.02 260). Dark ground oklch(0.19 0.022 258), ink oklch(0.95 0.008 250). Accent megha blue: light oklch(0.53 0.16 255) with white text, dark oklch(0.8 0.1 235) with dark text. Green only for passed checks.
- Shape: 12px radius on windows and cards, 8px on buttons inside them, pills for chips. 1px borders from one --border token; one soft shadow, only on the thread mock.
- Imagery: the product itself, drawn in HTML: a T3 thread with the cloud setup log, a command and a streaming answer. Labeled as an illustration.
- Signature: the cloud speech-bubble mark (assets/icons), used in the nav, the provider chip and the footer. Nowhere else.
- Voice: plain, specific, honest about limits. Errors and money: plain and calm.
- Density and pace: persuade surface, comfortable. Instant hovers; one short reveal of the mock's log on load (skipped with reduced motion); copy feedback ~200ms.

## Standard
Layout, navigation, controls and states follow the platform and Critly's concepts.
