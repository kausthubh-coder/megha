# site

The public page for megha: what it is, a drawn T3 thread running in the cloud, and the install prompt.

```
PORT=3417 bun run dev     # from the repo root: bun run dev
bun run test              # prompt builder and config snippets (bun test)
bun run lint
bun run typecheck
bun run build
```

- `app/` holds routes only. Feature code lives in `features/<name>/`.
- `features/install/install.ts` is the one source for the install prompt, the manual steps and the T3 and Zed
  config snippets. Change install instructions there, and its tests will tell you if the prompt and snippets
  disagree.
- The look is written down in `.critly/direction.md`. Tokens are in `app/globals.css`.
- Favicons in `app/` are generated by `assets/icons/build.mjs` (`bun run icons`).
